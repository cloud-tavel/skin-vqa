## E3 rank16 全量评估（基线）

配置：Qwen2.5-VL-7B + LoRA rank16，测试集 505 例。

> ⚠️ 该测试集由训练集按类别分层抽样构建，与训练集**同源**，指标反映的是训练数据内重测水平，不能代表泛化能力。真实泛化结果见 E7。

| 类别 | 正确/总数 | 准确率 |
|---|---|---|
| nv 黑色素细胞痣 | 269/290 | 92.8% |
| vasc 血管病变 | 7/10 | 70.0% |
| bcc 基底细胞癌 | 21/33 | 63.6% |
| bkl 良性角化病 | 34/70 | 48.6% |
| mel 黑色素瘤 | 26/71 | 36.6% |
| akiec 光化性角化 | 6/21 | 28.6% |
| df 皮肤纤维瘤 | 0/10 | 0.0% |
| **micro** | **363/505** | **71.88%** |
| **macro** | — | **48.59%** |

分析：准确率与训练样本量单调相关（nv 6705 张 → 92.8%；df 115 张 → 0%），典型类别不均衡。无法解析样本 0 条，排除输出格式漂移。

步骤：`merge_lora.py` 合并适配器 → vLLM 常驻服务（`--max-model-len 4096 --served-model-name skin-vqa --gpu-memory-utilization 0.90`）→ FastAPI 转发。

## E5 推理侧提示词消融（负结果）

设计：同一测试集、同一模型、同一解析器，仅在问题后追加黑色素瘤临床鉴别特征提示词（ABCD 准则、色素网络、伪足、蓝白幕）。

| 指标 | 基线 | 加提示词 |
|---|---|---|
| micro | 71.88% | **31.68%** |
| mel | 36.6% | 83.1% |
| nv | 92.8% | 28.6% |
| bcc / akiec | 63.6% / 28.6% | 0% / 0% |

归因：提示词引入「黑色素瘤先验偏好」，模型系统性将大量 nv 判为 mel，并非格式漂移。

**结论：对 LoRA 微调后的模型，推理侧提示词无法实现类别纠偏，反而制造新偏差；少数类问题必须回到训练侧解决。**

## E7 类别平衡重训 + 病灶级互斥复评

方案：

- **B1 平衡采样**：`WeightedRandomSampler` 按类别频率反比采样，`w = N / (K · n_i)`，承担类别平衡主责；
- **A1 Focal Loss**：在因果语言建模交叉熵上套 Focal（γ=2.0），聚焦难分样本；
- 其余超参与基线一致（LoRA r16/α32，lr 5e-5 cosine，batch 2 × accum 8，3 epoch）。

数据：先用 `data/split_train_test.py` 按 `lesion_id` 做病灶级严格互斥划分——可用样本 7872 条 → 训练 6299 / 评估 1573，图片级与病灶级重叠校验均为 0。

执行：互斥训练集约 93 分钟，loss 由 1.87 收敛至 0.004。LoRA 注入范围为语言塔全部线性层 + `lm_head` + 视觉塔 MLP（约 50M 参数）。

互斥复评结果：

| 指标 | 基线（505，同源） | 平衡重训（1573，互斥） |
|---|---|---|
| micro | 71.88% | **74.25%（1168/1573）** |
| macro | 48.59% | **55.81%** |
| df | 0% | **39.1%** |
| akiec | 28.6% | +20.6pp |
| mel | 36.6% | +7.8pp |
| nv | 92.8% | 93.1% |
| bcc / vasc | 63.6% / 70.0% | 轻微回落 |

预期 vs 实测：方案原预期 macro ≥60%、mel ≥60%，实测 macro 55.81%、mel 44.4%，**未达预期**。主要原因是 df/mel 可用训练样本少（df 仅 92 张）且语料为模板化构造、长尾类细粒度混淆严重。该结果如实保留，未通过调参掩盖。

## 工程约束（踩坑沉淀）

1. 同一时刻 GPU 只能运行一个任务（训练 / 评估 / 服务互斥）；
2. vLLM 常驻占用 90% 显存，跑评估或训练前必须先停服务，否则模型被挤到 CPU；
3. LoRA 部署前必须合并进基座，vLLM 加载的是合并权重；
4. 大文件传输后必须校验完整性（zip 大小、safetensors 元数据）；
5. 公网映射地址在实例重启后会变化，小程序 `baseUrl` 需同步更新；
6. 非标端口在部分移动网络会被拦截，演示环境优先使用稳定网络。
